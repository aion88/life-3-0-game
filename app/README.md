# Application Life 3.0

TypeScript strict, Vite, Three.js, Zod ; interface DOM/CSS sans framework. Versions exactes : `package.json` et `package-lock.json`.

Depuis ce dossier :

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4191
npm run release:check
```

`release:check` exécute TypeScript, ESLint, Vitest, le build et les contrôles du paquet. Les tests navigateur sont séparés : `npm run e2e` (Playwright).

## Carte du code actif

- `src/main.ts`, `src/app/`, `src/screens/` : démarrage, navigation et écrans d’accueil, questionnaire et rétrospective.
- `src/questionnaire/`, `src/fastforward/` : choix de départ et trajectoire vers le monde.
- `src/worlds/` : parcours courts, décors illustrés, casting, conséquences, fiches et exploration.
- `src/street/episode/` : épisode 1984. Le parcours hebdomadaire historique reste distinct.
- `src/save/`, `src/shared/`, `src/engine/` : sauvegarde/rejeu et primitives. Préserver la compatibilité des sauvegardes existantes.
- `public/illustrated/` : décors et affiches publiés. `src/worlds/illustrations.json` définit les images réellement jouées.
- `tools/` : génération des sources et galerie, validation des images, empreinte de livraison.
- `tests/unit/`, `tests/e2e/`, `tests/e2e-street/` : vérifications ciblées et parcours navigateur.

Les dialogues actuels vivent aussi dans les modules TypeScript des parcours ; l’ancien guide qui les plaçait tous dans `src/data/strings/` n’est plus exhaustif. Chercher le texte et ses consommateurs avant modification.

## Build et livraison

`npm run build` régénère la galerie, produit `dist/` puis `dist/release.json`. `npm run check:deploy` contrôle les assets, leur taille, leur résolution et l’absence de fichiers privés. Ne pas modifier `dist/` manuellement.

Déploiement statique (Cloudflare Pages) : sortie `app/dist/`, base `/`. Aucun secret applicatif requis. Les clés de sauvegarde et données de progression restent locales ; ne pas les réinitialiser pour contourner un bug.

Les profils Playwright iPhone/Android tournent sur Mac : ils ne remplacent pas une vérification sur téléphone physique.

La liste de ressources `src/screens/lang/resources.json` est versionnée ; `npm run generate:resources` la régénère à partir de notes de recherche qui ne sont pas dans ce dépôt.

`public/apercus/` previews are generated by the street e2e suite (not versioned).
